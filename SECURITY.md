# Security and Sensitive Material

Figure Craft is a documentation, styling, and rendering reference package. Do not commit credentials, private datasets, unpublished results, personal information, or absolute paths from a local research environment.

If you find a credential or other sensitive material, do not open a public issue. Contact the maintainer privately through the GitHub profile and include the affected path and commit when safe to do so.

For scientific or image-integrity concerns, open a private maintainer report first when public discussion could expose unpublished material.
