# Contributing to Figure Craft

Figure Craft values clear scientific meaning, calm visual judgment, and practical reusable craft.

## Before opening a change

- Read [SKILL.md](SKILL.md) and the relevant reference before changing the system.
- Keep the entrypoint light; put detailed guidance in the smallest useful reference.
- Preserve scientific meaning, source provenance, and explicit uncertainty.
- Check the license and attribution of any added font, image, code, or external example.

## Pull requests

Describe:

- what changed and why;
- which visual or scientific decision it supports;
- what checks you ran;
- any remaining limitations, venue-specific assumptions, or asset-license questions.

For renderer or layout changes, include the relevant output or a clear description of how to reproduce it. Do not add generated caches, private research data, credentials, or local absolute paths.

Contributions are accepted under the [Apache License 2.0](LICENSE), unless a separate written agreement says otherwise.
